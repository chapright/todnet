# Todnet

<p align="center"><img src="assets/fox/fox-app.svg" width="160" alt="Todnet"></p>

[English](README.md) · [فارسی](README.fa.md)

کلاینت بومی ویندوز برای دادهٔ VPN رایگانی که همراه با حساب فایرفاکس ارائه می‌شود — نسخهٔ ویندوز کلاینت اندروید [Vauth/FoxyVPN](https://github.com/Vauth/FoxyVPN).

Todnet غیررسمی و مستقل است. هیچ وابستگی، تأیید یا پشتیبانی‌ای از سوی Mozilla ندارد.

## پیش‌نیازها

- ویندوز ۱۰ نسخهٔ 1809 یا جدیدتر، یا ویندوز ۱۱ — ۶۴ بیتی
- یک [حساب رایگان فایرفاکس](https://accounts.firefox.com)
- پورت خروجی TCP 2499

WebView2 به‌صورت پیش‌فرض در ویندوز ۱۱ موجود است. در ویندوز ۱۰، اگر WebView2 نصب نباشد، برنامه رابط کاربری را در مرورگر پیش‌فرض شما باز می‌کند.

## نصب

از [آخرین انتشار](../../releases/latest) دانلود کنید:

- **نصاب** — `Todnet-<version>-setup.exe`
- **قابل‌حمل** — `Todnet-<version>-windows-x64.zip` (استخراج کنید و `Todnet.exe` را اجرا کنید)

این فایل‌ها هنوز امضای دیجیتال ندارند. اگر SmartScreen ویندوز نمایش داده شد، گزینهٔ **More info → Run anyway** را انتخاب کنید.

## شروع سریع

1. Todnet را اجرا کنید.
2. با حساب فایرفاکس خود وارد شوید.
3. یک موقعیت انتخاب کنید، یا **Auto-select** را روشن بگذارید.
4. دکمهٔ روشن/خاموش را بزنید.

## امکانات

- حالت **System proxy** (پیش‌فرض، بدون نیاز به دسترسی مدیر) و حالت **TUN** (همهٔ برنامه‌ها، نیازمند دسترسی مدیر)
- پروکسی‌های HTTP و SOCKS5 روی `127.0.0.1`
- ۳۳ کشور به‌همراه گزینهٔ پیشنهادی سریع‌ترین لبه، با تأخیر زنده
- چند حساب فایرفاکس با سهمیهٔ مجزای هر حساب، قابل جابه‌جایی
- آیکن سینی سیستم، اجرای خودکار اختیاری هنگام شروع، و گزارش‌های زنده
- انگلیسی و فارسی، با چیدمان کامل راست‌به‌چپ

حالت TUN فقط TCP را منتقل می‌کند، از جمله DNS-over-HTTPS. بسته‌های UDP رد می‌شوند تا برنامه‌ها به TCP برگردند.

## داده‌ها

تنظیمات، حساب‌ها و گزارش‌ها در `%APPDATA%\Todnet\` ذخیره می‌شوند. برای بازنشانی کامل برنامه، این پوشه را حذف کنید.

## فایل‌های انتشار

هر انتشار شامل نصاب، نسخهٔ قابل‌حمل، و `SHA256SUMS.txt` برای بررسی صحت دانلودهاست.

## سلب مسئولیت

کلاینت غیررسمی. با حساب فایرفاکس خودتان و در چارچوب سهمیهٔ رایگان ۵۰ گیگابایت در ماه که Mozilla ارائه می‌دهد استفاده کنید. شرایط استفادهٔ Mozilla را رعایت کنید.
